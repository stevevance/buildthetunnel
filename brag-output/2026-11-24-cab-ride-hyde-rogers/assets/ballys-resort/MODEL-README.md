# Bally’s Chicago — exterior model

Open **Ballys-Chicago.html** in a desktop or mobile browser with WebGL 2 enabled. The viewer includes Three.js and all model assets and works offline. The reference links inside Model notes open public sources when connected.

**Ballys-Chicago.glb** is a portable model for Blender and other glTF 2.0 applications. The resort and surrounding Chicago massing are separate named root groups. Hide the city massing for an unobstructed model study. The glTF carries geometry, PBR materials, sign textures and vertex colors. It contains a portable water material. The interactive HTML additionally supplies a live reflection, camera presets, project labels, and day and dusk illumination.

**Ballys-Chicago-Exterior.jpg** is a perspective rendering of the exported model. Two foreground context buildings are hidden in that view to reveal the riverfront park. Both are included in the model.

**Ballys-Chicago-Reference-Guide.pdf** contains an illustrated site plan, elevation study and a clickable reference index.

## Design basis

The HKS Phase 1 site-approval drawings updated January 21, 2025 control the layout. Bally’s July 2024 announcement establishes the hotel at the southern end. The tower sits at the bend in the west bank, immediately northwest of the riverfront park. Its long axis runs northwest to southeast. The rectangular event wing between the casino and hotel has its own lower roof. The main parking decks are integrated with the casino.

The model reconstructs the intended finished exterior. Public renderings and 2026 construction photographs supplement the drawing set. Upper tower proportions, the north parking roof outline and the riverfront footprint were compared across multiple sheets. The tower is approximately 136 m high. Colors, small profiles, exact floor elevations, pool and furniture arrangements, park objects and the continuation of the riverwalk to Grand Avenue are approximate. People, cars and the water taxi illustrate scale. Future parcels are left open. All urban context is generalized. Field measurements and construction BIM were unavailable for verification.

## Editable Three.js source

Inside the source directory, geometry is generated by named ES modules. Metres are used throughout. Y is up, positive X is east along Chicago Avenue and positive Z is south.

| Module | Contents |
| --- | --- |
| scene.js | Assembly and hotel registration |
| tower.js | South hotel envelope, cladding, terrace, crown and signs |
| garage.js | Integrated parking envelope, green roof and Chicago Avenue frontage |
| podium.js | Main casino, theater, dining terraces, entrances and hotel podium |
| landscape.js | Gardens, promenades, park, arrival drives and planting |
| district.js / context-data.js | River, bridges, mapped streets and surrounding massing |
| entourage.js | Illustrative people, street furniture, vehicles and water taxi |
| viewer.js / style.css / app.html | Navigation, layout, lighting and source notes |

To run after editing, start a local static server in the source directory.

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000/app.html`. The vendored Three.js r170 module requires no package installation. To re-export the portable model, visit `http://localhost:8000/work/export/export-glb.html` and use the download control. The export tool bakes repeated geometry and instance colors for compatibility.
